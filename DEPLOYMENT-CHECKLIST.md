# Deployment checklist

- [ ] Create Supabase project
- [ ] Run `supabase/schema.sql` in SQL Editor
- [ ] Copy project URL and anon/public key
- [ ] Push project files to GitHub
- [ ] Import GitHub repo into Vercel
- [ ] Set `NEXT_PUBLIC_SUPABASE_URL`
- [ ] Set `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- [ ] Deploy and confirm build succeeds
- [ ] Set Supabase Auth Site URL to Vercel URL
- [ ] Create owner account and farm workspace
- [ ] Test creating item, purchase, usage, labour and expense
- [ ] Create a second account and add it to `farm_members`
- [ ] Test shared records and access boundaries
- [ ] Set up database backups
